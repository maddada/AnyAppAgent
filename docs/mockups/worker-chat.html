Kiwimake · helpers mockup

App chat: helper rows and a helper's chat

The main chat stays your conversation with the app. Each piece of work shows as one helper row, and tapping it opens that helper's own chat.

Mockup, nothing built yet 8 row states Helpers work side by side Workbench colours Light and dark: the theme switch flips it

Phone

Left: the main chat answering while two helpers work side by side, each in its own copy of the app. The Stop under the reply stops only that reply; the helpers keep going. Right: the helper's chat that opens from its row. It is read only: its own Stop, and anything you want to tell it goes through the main chat.

Desktop

The helper's chat opens beside the main chat, so the main chat stays in front of you and you can keep talking. In a narrow window it drops below.

Every state of a helper row

A mark and a word from the app's state line, then the helper's latest line: its current step while it works, its result once it is done. Changes are added to the app one at a time, so a finished helper can wait a moment to add its change.
